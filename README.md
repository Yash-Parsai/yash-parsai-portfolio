# Yash Parsai — Portfolio

Dark, red-accented personal portfolio for Yash Parsai.

## Run locally

Open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Photo

- `assets/profile.jpg` = original photo (kept unchanged)
- `assets/profile-cutout.png` = transparent cutout used by the hero section

The hero CSS handles the final fade into the black background. If you replace the photo later, replace `profile-cutout.png` with another transparent PNG and keep the same filename.
